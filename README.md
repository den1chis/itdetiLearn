# itdetiLearn — ученический сайт ITdeti

Чистый HTML + JS, без сборки и фреймворков. Работает с API `den1chis/itdeti` (маршруты `/student/...`).

## Запуск локально

1. Запустите бэкенд (`itdeti`): `python -m uvicorn main:app --host 0.0.0.0 --port 8000`.
2. В этой папке: `python -m http.server 5500`.
3. Откройте http://localhost:5500.

Адрес API задаётся в одном месте — `config.js` (по умолчанию `http://localhost:8000`).
Порт 5500 уже добавлен в CORS бэкенда (`main.py`, `STUDENT_SITE_LOCAL_ORIGINS`); для другого адреса
добавьте его в `CORS_EXTRA_ORIGINS` в `.env` бэкенда.

Тестовые ученики создаются скриптом `itdeti/scripts/seed_dev.py` (логины и пароли — в его описании).

## Страницы

`#/login` → `#/courses` (мои курсы) → `#/course/<id>` (модули и уроки с отметками) → `#/lesson/<id>`
(материалы-ссылки, тексты, задания, кнопка «Урок пройден»). Кнопка «Выйти» в шапке.

## Устройство

- `config.js` — адрес API.
- `app.js` — вся логика; данные с сервера выводятся только через `textContent`, ссылки — только `http(s)`.
- `style.css` — цвета как в CRM, крупные шрифты и кнопки (дети 8–15 лет, сначала телефон).
- Токен ученика живёт 2 часа (настройка бэкенда `STUDENT_TOKEN_EXPIRE_MINUTES`) и хранится в `localStorage`;
  после истечения сайт показывает вход с сообщением.
